# Mars鹏作品集 - 阿里云部署清单

## 当前部署与素材保护（2026-09-13）

- 网站通过 GitHub Pages 发布，仓库为 `soma969612889-star/MARSXPO`，域名为 `www.marsxpo.com`。
- 素材使用上海 OSS Bucket `marsxpo-assets-2026`；页面中的 `MARS_ASSET_BASE_URL` 必须保留该 OSS 地址。
- 网页视频使用 `作品选集_预览/` 下的 38 个压缩水印 MP4，原始文件仍保留在本地及原有 OSS 目录。
- 作品图片和视频限制右键菜单、拖拽保存；兼容浏览器中隐藏视频下载入口，并限制媒体长按菜单。这些只是界面限制，不是加密。
- OSS 防盗链已设置以下 Referer 白名单，空 Referer 不允许，截断 QueryString 允许，黑名单为空：

```text
https://www.marsxpo.com
https://marsxpo.com
http://www.marsxpo.com
http://marsxpo.com
https://oss.console.aliyun.com
```

验收应使用 GET 或带 Range 的 GET 请求：网站来源返回 200/206，空来源及其他网站来源返回 403。HEAD 请求不能用来判断防盗链是否生效。

启用后，本地 file:// 页面及未加入白名单的预览站点无法直接加载线上 OSS 素材。本地测试可以使用本地素材；如需新增正式域名，应先更新白名单。

Referer 可被伪造，防盗链无法彻底阻止下载、截图或录屏。不要将这套设置视为原片私有存储；更严格的保护需要私有源文件和服务端鉴权。不要直接把当前 Bucket 改为私有，否则现有静态网页将无法加载素材。

以下为早期整站 OSS 托管方案，和当前 GitHub Pages 部署不同。

## 推荐方案

使用一套阿里云 OSS Bucket 托管整个网站：

- `index.html`、`styles.css`、`script.js` 放在 Bucket 根目录
- `作品选集/` 整个文件夹也放在 Bucket 根目录
- Bucket 开启静态网站托管，默认首页为 `index.html`
- `www.marsxpo.com` 通过 CDN 或 OSS 自定义域名指向这个 Bucket

如果后续想把媒体独立到 `media.marsxpo.com`，只需要把 `index.html` 中这一行改成媒体域名：

```html
window.MARS_ASSET_BASE_URL = "https://media.marsxpo.com";
```

当前留空即可，本地和同 Bucket 部署都会自动识别。

## 上线前需要确认

1. `marsxpo.com` 是否已经完成 ICP 备案。
   - 如果使用中国大陆 OSS / CDN 并绑定 `www.marsxpo.com`，通常需要备案。
   - 如果还没备案，可以先用 OSS 临时域名预览，或选择香港/海外节点临时上线。

2. OSS Bucket 区域。
   - 国内观众为主：建议华东 2 上海、华北 2 北京、华南 1 深圳等大陆区域。
   - 未备案但想先上线：可考虑中国香港区域。

3. 视频体量。
   - 当前 `作品选集` 约 10.29GB。
   - 单个视频较大，正式访问时建议后续压缩一版网页用视频，减少加载等待和流量费用。

## OSS 目录结构

上传后 Bucket 根目录建议如下：

```text
/
  index.html
  styles.css
  script.js
  作品选集/
    剪辑包装/
    动画/
    展实拍/
    漫游/
    建模/
    学生时期/
```

不要把 `index.html` 放在 `作品集网页/` 子目录里作为网站入口；正式网站入口应该在 Bucket 根目录。

## 阿里云控制台步骤

1. 进入 OSS 控制台，新建 Bucket。
   - Bucket 名称示例：`marsxpo-web`
   - 读写权限：公共读，或使用 CDN 回源鉴权方案
   - 区域按备案情况选择

2. 上传网站文件。
   - 把 `E:\01作品\作品集网页\index.html`
   - 把 `E:\01作品\作品集网页\styles.css`
   - 把 `E:\01作品\作品集网页\script.js`
   - 把 `E:\01作品\作品选集` 文件夹
   上传到 Bucket 根目录。

3. 开启静态网站托管。
   - 默认首页：`index.html`
   - 默认 404 页面：`index.html`

4. 绑定域名。
   - 推荐使用 CDN 加速域名：`www.marsxpo.com`
   - CDN 源站选择 OSS Bucket 外网访问域名
   - CDN 创建后，阿里云会给一个 CNAME 地址

5. 到域名解析里添加记录。
   - 主机记录：`www`
   - 记录类型：`CNAME`
   - 记录值：CDN 给出的 CNAME 地址

6. 配置 HTTPS。
   - 在 CDN 域名里申请或上传 SSL 证书
   - 开启 HTTPS 访问
   - 可开启 HTTP 自动跳转 HTTPS

## 验收清单

上线后检查：

- `https://www.marsxpo.com/` 能打开首页
- 顶部显示 `Mars鹏作品集`
- 分类、搜索可以使用
- 点击作品后，图片/视频能正常加载
- 手机浏览没有横向滚动
